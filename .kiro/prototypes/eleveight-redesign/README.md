# Eleveight-Inspired Redesign Prototype

## Inspiration
Based on [Eleveight Studio](https://www.eleveight.studio/) — a dark, editorial, immersive single-page design.

## Design Direction
- **Dark-first palette**: Deep charcoal/near-black backgrounds with white text
- **Editorial typography**: Large, bold headlines with generous spacing
- **Minimal UI**: Clean lines, subtle borders, no heavy shadows
- **Grid-based layouts**: Structured project showcases
- **Smooth animations**: Scroll-driven reveals, subtle hover states
- **Monochromatic + single accent**: Warm accent color for CTAs and highlights
- **Generous whitespace**: Breathing room between sections

## Structure (same as current site)
1. Nav (minimal, transparent)
2. Hero (large headline, subtitle, CTA)
3. What We Do (capabilities list)
4. Services (service cards)
5. About (team description + image)
6. CTA Banner (conversion prompt)
7. Projects (project grid)
8. Contact (form + info)
9. Footer

## How to Apply
Copy the prototype files into the main `components/`, `app/`, and config files to apply the redesign.
